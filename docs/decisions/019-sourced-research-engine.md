# 019: One source-checking engine: the agent researches, code checks and writes the document

**Decision.** Show notes, pre-air verify and deep dives all run on one engine. The agent (Hermes, the AI that does Air Check's research) searches and decides what each source says. Code does everything that has an exact right answer: which track is which, which web address a source has, whether a fact has two sources or one primary source, the status of every fact, every count and date, and the finished document. Web search (Tavily, the search service that also earns the hackathon's Best Use of Tavily bonus) moves out of the agent's sandbox and into the bridge (the small host-side program the agent already uses to reach Crate), so code sees every search result the agent sees.

**Why this came up.** Tarik makes show notes today with a Perplexity prompt and pastes them into Dropbox Paper, and facts in them have been wrong before: the January 2026 notes had citations that did not match their claims. The PRD asks for the opposite: every fact linked, release dates, labels and credits backed by two sources or a primary source (the label, the artist or a press release), or marked **[verify]**. Two recent incidents shape how. On Oct 29 every package draft was refused because the model was asked to retype a 31-track tracklist exactly and changed curly quotes and accents (ruling R9). The same night the agent wrote itself five skills that contradicted the station's own. So the model should not be trusted to copy exact data, and the rules should not live only in text the model may or may not read. If we get this wrong, Air Check produces the same unreliable notes Tarik already has, only faster, and with an "every fact has a source" label that is not true.

**Options.**
- **A. The agent researches and judges; code checks, counts and writes (chosen).** The agent cites short ids that code issued (`S7k2q` for a source, `H1.4` for a track, `L23` for a line of notes); code fills in the real web address, track name and original line. A source only counts for a date or label if its own text shows that value. Cost: the most new code of the three (two tables, a source ledger (a short-lived list, kept by the bridge, of every source a search returned), two agent tools, a research page), and the agent cannot quote a page it found some other way.
- **B. The agent writes the whole notes document and code checks it afterwards.** Closest to the Perplexity prompt and the least code. Cost: the model would copy every URL and track name itself, which is the copying that broke drafts on Oct 29, and code could not tell whether a cited page exists or says what the note claims. This is how the January citations went wrong.
- **C. A plain program does the research with no agent.** A host service calls Crate, Tavily and Nemotron directly. Easy to test. Cost: research leaves the sandbox and its audit log, which is the privacy story judges score, and Stage One of the hackathon expects the agent tools (Hermes, OpenShell) to be used. It would also be a second agent beside the one Air Check already runs.

For web search specifically: keep Tavily inside the sandbox as it is today (no work, and the sandbox log shows `api.tavily.com` directly), or move it to the bridge (chosen). Today's sandbox setup also lets the agent ask Tavily to read any page on its behalf (`/extract`), which we could not switch off (decision 006 addendum), and code never sees the results, so it cannot check a citation.

**What we chose and why.** Option A, with search on the bridge. Claude, pending Tarik's review. Tarik made three calls on Oct 29: close the sandbox's own Tavily door, use the free Tavily plan with daily caps, and keep Nemotron Super only. It is the only option where "every fact has a source" is checked by code rather than promised by the model. It applies the R9 lesson (code fills exact data), the decision 015 lesson (the skill text travels in the prompt, so the agent cannot skip it) and decision 011's pattern (the agent saves through one narrow route that can write nothing else). Moving search to the bridge also follows the project rule of one client module per outside service, and it gives the judges' demo workspace a working Tavily search for the first time (its sandbox has none).

**What we gave up.**
- The sandbox's audit log will show the agent reaching the bridge, not `api.tavily.com`. Tavily's part is visible as `tavily` source chips on each fact, not as a line in the network log, which is a slightly weaker video moment for the Tavily bonus.
- Stricter means more **[verify]** flags. A release date the agent read correctly still counts as unchecked if the search snippet happens not to show it. Some true facts will be flagged until Tarik or a second search confirms them.
- More to run: two tables, two agent tools, a ledger that forgets everything when the bridge restarts (a run in progress then has to search again), a Thursday and Friday schedule and a new Telegram line.
- Removing the sandbox's own Tavily key means rebuilding the agent's sandbox from scratch (Tarik's call). That costs a few minutes of downtime. Tarik also has to run a script that puts back the research tools, the station skills and the lock that stops the agent writing its own skills.
- Tarik's Tavily plan is the free one (about 1,000 searches a month), so research gets 30 searches a day and the judges' demo 10. Most facts will come from Crate, and on a busy day more of them will stay **[verify]**.
- No Nemotron Nano: research uses the larger Nemotron 3 Super throughout, because spike V3 found Nano less exact (Tarik confirmed, Oct 29). The video's "Nano vs larger Nemotron" panel has nothing to show from this feature.

**How we'll know if this was right.**
- Every link in an exported show-notes document opens a page that came back from a search Air Check ran (the ledger makes this checkable), and no date, label or credit is marked confirmed with fewer than two publishers or one primary source (the tests pin this).
- For the first real show, Tarik reads the notes beside his Oct 16 Paper notes and says he would use them, and he finds no fact marked confirmed that turns out wrong before air.
- Across the next four shows, fewer than half of release dates end up as **[verify]**, and no closing track ever gets an entry.
